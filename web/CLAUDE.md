# Woodsman 개발 지침

이 저장소에서 작업하는 사람과 AI 모두 이 규칙을 따른다.
프로그램이 커지고 있고 **혼자 오래 유지보수**해야 하므로, 나중에 읽는 사람이
"왜 이렇게 했는지" 알 수 있는 상태를 유지하는 것이 최우선이다.

## 1. 모듈로 쪼갠다 (필수)

| 무엇을 | 어디에 |
| --- | --- |
| **판단 로직** (정책·계산·검증) | `src/lib/*.ts` — 순수 함수. React·DB·환경 의존 없음 |
| **DB 질의** | 기능별 repository (`src/features/<도메인>/repository.ts`, `src/lib/*-repo.ts`) |
| **화면** | `src/features/<도메인>/ui/*.tsx` · 공용은 `src/components/` |
| **라우트** | `src/app/**` — 조립만 한다. 판단·질의를 여기 넣지 않는다 |

- 한 파일이 커지면 **먼저 쪼갠다.** 화면 파일 안에 정책 판단이나 SQL이 들어가면 잘못된 신호다.
- 순수 함수 모듈에는 **테스트를 붙인다.** 규칙이 바뀌면 테스트가 먼저 깨져야 한다.
- 수정도 모듈 단위로 나눠 진행한다.

현재 순수 모듈: `access` `site-policy` `site-status` `performance` `outbound` `ads`
`auth-providers` `site-url` `site-links` `format` — 전부 테스트가 있다.

## 2. 변경은 로그로 남긴다 (필수)

[`CHANGELOG.md`](./CHANGELOG.md)에 **모듈별**로 적는다.

- "무엇을 바꿨나"보다 **"왜 그렇게 했나"**. 코드를 보면 아는 건 생략한다.
- 되돌리면 안 되는 결정에는 **⚠** 를 붙인다.
- 사고가 났으면 **증상 → 원인 → 결정 → 재발 방지** 순으로 남긴다.

## 3. 조용한 실패를 만들지 않는다 (필수)

이 프로젝트에서 가장 크게 데인 부분이다.

> 배포는 성공하고 화면도 떴는데 **모든 DB 호출이 실패**하고 있었다.
> 실패 결과가 "설정이 비어 있는 정상 상태"와 똑같아 보여서 아무도 몰랐다.

- 실패 시 안전한 기본값으로 응답하는 건 좋다. **다만 반드시 `console.error`로 남긴다.**
- "값이 없음"과 "읽지 못함"이 같은 화면이 되지 않게 한다.
- 조용히 다른 경로로 떨어지는 폴백(예: DB 못 붙으면 로컬 파일로)을 만들지 않는다.
  경로가 갈리면 "로컬은 되는데 배포만 죽는" 사고가 난다.

## 4. 배포 대상은 Cloudflare Workers다

- **런타임에 Prisma를 쓰지 않는다.** OpenNext 번들에 Prisma WASM 엔진이 들어가지 않아
  첫 쿼리에서 죽는다. 질의는 `src/lib/d1.ts`의 D1 바인딩으로 한다.
  Prisma는 **스키마 정의와 마이그레이션 생성**에만 쓴다.
- `getCloudflareContext()`는 **반드시 `{ async: true }`**. 동기 모드는 정적 생성에서 실패한다.
- SQL에 값을 직접 끼워 넣지 않는다. `?` 바인딩만 쓴다.
- 스키마를 바꾸면 `npm run db:migrate` → 마이그레이션 파일을 **커밋**한다.
  배포 시 GitHub Actions가 D1에 자동 적용한다.

## 5. 사이트의 목적을 기준으로 판단한다

**1순위는 티스토리 블로그로 트래픽을 보내는 것**이다. 사이트 체류시간이나 광고 수익이 아니다.

- 자리 경쟁이 붙으면(예: 글 본문 끝) **티스토리 CTA가 광고보다 우선**한다.
- 성과 지표는 `/admin` 최상단의 **"티스토리로 넘어간 클릭"**이다. 페이지뷰가 아니다.
- 티스토리 원문 글은 **canonical을 원문으로** 지정한다. 전문을 복제하지 않는다.
- 사이트 고유 콘텐츠(계좌 공개·투자일지)가 검색 유입을 만드는 미끼다. 약화시키지 않는다.

## 6. 보안·정책 (되돌리지 말 것)

- ⚠ 시크릿은 **서버 전용**. `NEXT_PUBLIC_` 접두사 금지. `src/lib/env.ts`를 클라이언트에서 import 금지.
- ⚠ AI API 키를 **DB에 저장하지 않는다.** env 변수명만 기록하고 화면엔 "연결됨/미설정"만.
- ⚠ 가입은 **항상 USER**. `role`을 폼·API로 받지 않는다. ADMIN은 시드로만 만든다.
- ⚠ 로그인 실패 사유를 구분해 알려주지 않는다(계정 존재 여부 노출 방지).
- ⚠ 리다이렉트 대상은 **등록된 것만**. 쿼리로 받은 URL로 이동하지 않는다(오픈 리다이렉트).
- ⚠ 커뮤니티·회원가입 코드는 **지우지 않는다.** 나중에 열려고 스위치로 잠가 둔 것이다
  (`src/lib/site-policy.ts`).
- ⚠ 가입을 열기 전에 `/privacy`를 먼저 갱신한다. 현재 "회원정보를 수집하지 않는다"고 명시돼 있다.

## 7. 끝내기 전에

```bash
npm run check    # typecheck → lint → test → build
```

- 전부 통과해야 커밋한다.
- 화면을 바꿨으면 **실제로 띄워서 눈으로 본다.** 차트 색을 반대로 칠한 적이 있는데
  숫자가 맞아서 테스트로는 안 잡혔다.
- 배포 후에는 **실제 배포본을 검증한다.** 로컬 통과가 배포 성공을 뜻하지 않는다.
