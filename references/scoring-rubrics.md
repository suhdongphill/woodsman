## <a name="c"></a>C — Current (최근 분기 영업이익/EPS 증가율)

오닐 기준: 최근 분기 EPS YoY **≥25%**, 가속 + 매출 동반.

**기본 매핑 (YoY 증가율 → 점수)**

| YoY | 점수 |
|---|---|
| ≥100% | 10 |
| 50~100% | 8~9 |
| 25~50% | 6~7 |
| 10~25% | 4~5 |
| 0~10% | 2~3 |
| 음수 | 0~1 |

**보정**
- `+1` 가속(이번 분기 증가율 > 직전 분기 증가율), 상한 10
- `−2` 품질 미흡(매출 정체인데 이익만 급증 = 일회성·원가절감 의심)
- **사이클 보정**: 전년 동기 기준이 음수/저점이면 YoY%는 허수 →
  ① 직전 고점 대비 회복률 또는 ② QoQ 순차 성장으로 평가, **자동 만점 금지(상한 8)**

## <a name="a"></a>A — Annual (연간 영업이익 성장)

오닐 기준: 연간 EPS **≥25%**, **3년 연속** 성장, ROE ≥17%.

**기본**: 3년 EPS CAGR로 매핑 (C와 동일 구간표).

**⚠ 사이클 예외 (필수)**: 기준연도(시작연도) 영업이익 ≤ 0이면 **CAGR 사용 금지**.
음수 기준연도에서 CAGR을 뽑으면 271% 같은 허수가 나온다.
→ 다음 trajectory 루브릭으로 대체 채점:

| 조건 | 가점 |
|---|---|
| 적자 → 흑자 전환 달성 | +3 |
| 3년 연속 이익 개선(우상향) | +3 |
| 전년 대비 +100%↑ 또는 전고점 회복 | +2 |
| 차년도 가이던스/컨센서스 추가 성장 | +2 |

합산 후 0~10 클립. 단 *회복 사이클*임을 메모하고 **상한 9** — 안정적 복리성장과 구분.

**금지 사항**
- 트레일링 단순 CAGR(저점→고점) 그대로 쓰기
- 2년+ 선행 컨센서스(FY+2 등)를 A의 주 근거로 쓰기 — 미래 성장은 N·구조적 추정 모듈로 분리

## <a name="n"></a>N — New (제품·경영·시장·신고가) + 구조 해자

| 하위 항목 | 만점 | 채점 기준 |
|---|---|---|
| 신제품/신기술 사이클 | 2.5 | 차세대 제품·수요 사이클 진입 |
| 신경영/구조개편 | 2.5 | 분사·턴어라운드·경영진 교체 등 변곡 |
| 신시장/TAM 확장 | 2.5 | 신규 수요처 CAGR(예: AI 니어라인) |
| 신고가/베이스 돌파 | 2.5 | 52주 신고가 근접·정상 베이스 돌파 |

합계 0~10. **해자 보정**: 합리적 과점(소수 경쟁자) = `+1`(상한 10).
경쟁 격화·진입장벽 붕괴 = `−2`.

> 기존 '경쟁기업 수 → 0점' 오류 교정: **과점은 감점이 아니라 가점.**
> (WDC·Seagate·Toshiba 3사 과점 = 해자 플러스 요인)

## <a name="s"></a>S — Supply & Demand (수급)

- 상승일 거래량 급증(평균 대비 +40~50%↑), 축적(accumulation) 우위: 고점
- 자사주 매입·유통주식 감소: 가점 / 대량 신주발행·오버행: 감점
- 유통주식 적을수록(중소형) 탄력 가점

## <a name="l"></a>L — Leader or Laggard (상대강도)

- RS Rating **≥80** 핵심: 90↑ → 9~10 / 80~89 → 7~8 / 70~79 → 5~6 / <70 → ≤4
- 업종 1~3등 + 50/200일선 위 가점 / 업종 후발·이평선 하회 감점

## <a name="i"></a>I — Institutional Sponsorship (기관)

- 기관 보유 수·순매수 증가 추세: 가점 / 우량 펀드 신규 편입: 가점
- 과보유(over-owned)·기관 이탈: 감점
- (가중치 10인 이유: 리테일 데이터 확보가 어려워 소폭 하향)

## <a name="m"></a>M — Market Direction (시장)

- Confirmed Uptrend(팔로스루 성립) → 8~10 / 분산일 누적·조정장 → ≤4
- 지수 50/200일선 관계로 판정
- **개별주는 시장에 종속** (오닐: 4종목 중 3종목이 시장을 따른다)
- **게이트 규칙**: M ≤ 3이면 composite 무관 신규 매수 보류

## <a name="example"></a>WDC 재채점 예시 (방법론 시연, 투자 권유 아님)

| 항목 | 기존 카드 | 개선판 | 근거 |
|---|---|---|---|
| C | 25/25 (=10/10) | **9/10** | YoY +116%(>100%) → 9~10, 매출 동반·가속 확인 시 10 |
| A | 10/25 (=4/10) | **7~8/10** | FY23 적자라 CAGR 무효 → trajectory(적자→흑자, 3년 개선, 차년 성장). 회복 사이클이라 상한 9 |
| N | 23/75 (=3.1/10) | **8/10** | Sandisk 분사(신경영) + AI 니어라인(신시장) + 3사 과점(해자 +1) |
| S·L·I·M | — | **N/A** | 거래량·RS·기관수급·지수추세 데이터 필요. **데이터 없이 점수를 만들지 않음** |

## <a name="impl"></a>구현 메모 (PMS 앱 연동)

- 백엔드 `canslim_score(ticker, financials, market)` → 항목별 dict + composite 반환
- 음수 기준연도 → `use_trajectory=True` 플래그로 분기 처리
- `scores(json)`에 항목점수 + 근거 1줄 + 데이터출처·기준일 저장 (`canslim_cache` 스키마 확장)
- 카드 UI: 7축 레이더(0~10) + 종합(100) + 등급 밴드

## 미결 사항
1. 가중치 동등(현행) vs N·L 가중 — 확정 필요
2. RS Rating 소스(자체계산 vs 시세 기반 근사)
3. 사이클 종목 자동 판별 기준(업종 태그 or 과거 적자분기 존재 여부)
