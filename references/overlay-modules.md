## <a name="lens"></a>1. 거장 렌즈 매핑 (어느 칸을 누가 맡나)

| 거장 | 이론 | 역할 | 가격 포함? |
|---|---|---|---|
| 오닐 | CANSLIM | 성장의 질 (C·A·N) | ✗ |
| 그레이엄 | 안전마진 | 하방·정규화 이익 밸류 | ✗ |
| 미너비니 | VCP/좌측꼬리 | 진입 타이밍 | (차트) |
| 막스 | 시계추·2차적 사고 | 사이클 위치 + 컨센서스 갭 오버레이 | ✓ |
| 모부신 | 기대치 투자 | 가격에 반영된 기대 정량화 | ✓ |
| 소로스 | 재귀성(reflexivity) | 가격↔펀더멘털 되먹임 국면 | ✓ |

**원칙: 가격이 안 들어간 축(질·하방)과 들어간 축(기대·되먹임)을 섞지 말고 곱한다.**

핵심 철학: 점수는 절대 등급이 아니라 **"성장의 질·지속성"을 비교하는 렌즈**.
높은 점수가 곧 매수 신호가 아니며, 반드시 밸류에이션(좋은 가격)·시계추(심리 위치)와
함께 본다. ("좋은 기업 ≠ 좋은 투자")

## <a name="overlay"></a>2. 컨센서스 갭 오버레이 (대칭, −10 ~ +10)

- 코어 점수와 별도로 적용: `조정 매력도 = 코어 + 오버레이`
- **대칭 구조**: 시장 기대 대비 펀더멘털이 좋으면 +, 기대가 과열이면 −
- **하드 실링**: ±10을 절대 초과하지 않음
- **근거 문서화 필수**: 오버레이 부여 시 어떤 컨센서스 대비 어떤 갭인지 1줄 이상 명시
- 어떤 모델도 사이클 변곡점을 정확히 예측하지 못한다는 한계를 보고서에 명시

## <a name="structural"></a>3. 구조적 추정 성장 모듈 (Driver × Share × Content)

컨센서스 점추정 대신 구동변수를 분해해 전파. **A를 대체하지 않고** N·밸류·시나리오로 라벨링.

```
공급사 성장 ≈ (구동변수 CAPEX/WFE) × (점유율: MOAT 방어) × (공정당 함량 증가)
```

- **구동변수**: 완성 제조사(삼성·SK·TSMC·Micron) CAPEX 가이던스.
  영업이익률은 성장률이 아니라 "CAPEX 지속·펀딩 가능성" 필터.
  고점 마진 외삽 금지 → 미드사이클/시나리오 밴드.
- **점유율**: MOAT가 방어. 독점=전환 안정, 범용=침식 위험.
- **함량**: ALD 스텝↑·NAND 단수↑·HBM 적층↑·검사 횟수↑ (사이클과 덜 연동, 알파 핵심).
- **층별 리드/래그**: 장비=선행(베타↑) · 소재가스=후행(함량 강) ·
  부품=동행~후행(연금성) · 검사계측=동행(함량 강).
  한 숫자를 전 층에 같게 곱하지 말 것.
- **출력**: 점추정 금지, 시나리오 밴드(불·기준·약세).

## <a name="reflexivity"></a>4. 재귀성 점검 (소로스)

가격↔펀더멘털 되먹임 국면을 식별:
- 주가 상승 → 자금조달 용이 → CAPEX/성장 가속 → 실적 개선 → 주가 상승 (양의 루프)
- 루프가 작동 중인지, 어느 단계인지, 끊길 트리거가 무엇인지를 보고서에 명시
- 재귀성 국면 판단은 M(시장방향)·오버레이와 교차 검증

## A 점수용 사이클 정규화 (v2 규칙, 참고)

사이클 산업에서 CAGR을 쓸 경우 셋 중 택1:
1. **창 확장**: 3년 대신 5~6년 CAGR로 한 사이클 포함
2. **미드사이클 영업이익**: 시작·끝점을 미드사이클 값으로 치환
3. **피크/트로프 보정**: 시작점이 저점이면 과대, 고점이면 과소임을 명시하고 할인

(기준연도가 적자인 경우는 scoring-rubrics.md의 trajectory 루브릭이 우선)
