## 1. 오늘 확인된 문제의 정체

어제 "화면이 `lib/mock.ts`를 읽어 버튼이 아무 데도 연결돼 있지 않다"를 다섯 곳 고쳤는데,
**같은 병이 다섯 곳 더 남아 있었다.** 지금 `@/lib/mock`을 읽는 파일 전부:

| 파일 | 무엇이 목업인가 | 증상 |
|---|---|---|
| `app/admin/comments/page.tsx` | `comments` `siteConfig` | **승인·숨김·삭제 버튼 3종이 `onClick` 없음.** 토글 3개는 `defaultOn`만, 금지어 "저장"도 무동작, 탭 4개는 장식 |
| `app/(public)/page.tsx` | `featuredStocks` | **홈 종목 카드 4개의 가격이 하드코딩**(TSM 191.2 · NVDA 148.7 …) |
| `app/(public)/stocks/page.tsx` · `stocks/[ticker]/page.tsx` | `stocks` `getStock` `mockSeries` | 종목 목록·상세 전체가 목업. 차트도 `mockSeries` |
| `app/sitemap.ts` | `stocks` | 존재하지 않는 종목 URL을 사이트맵에 싣고 있다 |
| `app/admin/feeds/page.tsx` | `feeds` `feedItems` | RSS 화면 전체 목업, 버튼 3종 무동작 |
| `app/admin/page.tsx` | `adminStats` `comments` `aiProviders` | 대시보드 상단 숫자(새 댓글·AI 토큰 사용량)가 고정값 |
| `app/(public)/board/*` · `insights/[slug]` | `getCommentsByPostId` `siteConfig` | 공개 댓글이 목업에서 나온다 |

**공통 처방은 어제와 같다**: `lib/*.ts` 순수 모듈(판단) → `features/<도메인>/repository.ts`(D1)
→ `actions.ts`(`"use server"`, async만) → 화면 교체 → **목업 export 삭제** → `mock.test.ts`로 부활 차단.

자동이면 홈이 항상 최신이지만 Yahoo 비공식 API에 의존한다. → **자동 수집 + 실패 시 기준일 노출**을 권한다.

## 권장 순서

```
A0·A1 (사람, 10분)
  └─ B 댓글 (반나절)      ← 죽은 버튼부터. 가장 위험하다
       └─ C 종목 시세 (하루)  ← 가장 눈에 띄는 가짜 숫자
            └─ D RSS·대시보드 (반나절)
                 └─ E GEO 2~4단계 (하루)
```

B와 C는 서로 안 겹쳐서 순서를 바꿔도 된다. **D는 C 다음**이 낫다 — 종목 화면이 살아나야
RSS로 끌어온 글에 종목을 붙일 수 있다.
