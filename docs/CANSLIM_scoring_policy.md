# CANSLIM 채점 정책 (WoodsMan 표준) — v1.0

> **용도**: 이 파일을 Claude 프로젝트 지침("PC 정책 파일")에 넣어두면, 앞으로 종목·보고서를 만들 때 항상 이 채점법으로 CANSLIM을 산출한다.
> **출처/근거**: 체슬리투자자문 리포트(2026.06.12)의 C·A·N 정량 채점법을 표준화. KLAC 26.0 / AMAT 28.6 계산을 역설계해 공식 확정.
> **성격**: 종목 비교용 분석 프레임. 투자 권유 아님. 모든 입력 수치는 1차 자료로 재확인.

---

## 0. 호출 방법 (Claude에게)

```
이 CANSLIM 채점 정책(CANSLIM_scoring_policy.md)대로 [종목/티커]를 채점하고,
WoodsMan 증권보고서 포맷(네이비-시안 HTML)으로 정리해줘.
- C·A는 공식대로 계산식 노출
- N은 5개 소항목 점수표
- 총점 /75 + (선택) S·L·I·M 정성 모듈
- 입력 수치 출처 명시, 미확인은 '확인 필요'
```

## 1. 점수 체계 개요

| 글자 | 항목 | 만점 | 방식 |
|---|---|---|---|
| **C** | 분기 영업이익 증가율 | 25 | 공식 |
| **A** | 3년 영업이익 CAGR | 25 | 공식 |
| **N** | New Product/Market/High | 25 | 5소항목 합산 |
| **합계(코어)** | | **75** | C+A+N |
| (선택) S·L·I·M | 수급·주도주·기관·시장 | 정성 | 확장 모듈 |

> 핵심 철학: 점수는 **절대 등급이 아니라 "성장의 질·지속성"을 비교하는 렌즈**. 높은 점수가 곧 매수 신호가 아니며, 반드시 **밸류에이션(좋은 가격)·시계추(심리 위치)**와 함께 본다. ("좋은 기업 ≠ 좋은 투자")

---

## 2. C — 분기 영업이익 증가율 (만점 25)

**공식**

```
C점수 = (분기 영업이익 YoY 증가율[%] − 5)
        상한 25, 하한 0
```

- 입력: 최근 분기 영업이익, 전년 동기 영업이익(조정 영업이익 기준 권장)
- YoY 증가율(%) = (최근분기 − 전년동기) / 전년동기 × 100

**예시 (KLAC)**: Q3 FY26 $1.45B vs Q3 FY25 $1.35B → YoY +7.4% → (7.4 − 5) = **2.4점**
**예시 (AMAT)**: Q2 FY26 $2.53B vs Q2 FY25 $2.18B → YoY +16.3% → (16.3 − 5) = **11.3점**

---

## 3. A — 3년 영업이익 CAGR (만점 25)

**공식**

```
A점수 = (최근 3년 영업이익 CAGR[%] − 5)
        상한 25, 하한 0
```

- 입력: 3개 회계연도 영업이익(예: FY23·FY24·FY25, 조정 기준 권장)
- CAGR(%) = ((마지막연도 / 처음연도) ^ (1/2) − 1) × 100  *(3개 연도 = 2년 구간)*

**예시 (KLAC)**: FY23 $4,298M → FY25 $5,248M → CAGR +10.6% → (10.6 − 5) = **5.6점**
**예시 (AMAT)**: FY23 $7,720M → FY25 $8,560M → CAGR +5.3% → (5.3 − 5) = **0.3점**

> 해석: AMAT처럼 C는 높은데 A가 낮으면 "최근 분기에 성장이 쏠려 있고 3년 추세는 둔화" → 지속성 의심 신호.

---

## 4. N — New Product / New Market / New High (만점 25)

5개 소항목 합산. 각 소항목 루브릭은 체슬리 예시(KLAC 18 / AMAT 17) 기반 표준안이며, 프로젝트에서 미세조정 가능.

| # | 소항목 | 범위 | 채점 기준(표준안) |
|---|---|---|---|
| 1 | 글로벌 탑티어 지위 | 0 ~ +10 | 압도적 1위 10 / 과점 선두 6~8 / 상위권 3~5 / 그 외 0 |
| 2 | 향후 20%+ 고성장 가능성 | 0 ~ +6 | 명확한 20%+ 성장 근거(공시·가이던스) 4~6 / 일부 1~3 / 없음 0 |
| 3 | 경쟁기업 수 (밀집도) | −3 ~ +3 | 경쟁 희소(과점) +0~+3 / 다수·강한 경쟁 −1~−3 |
| 4 | 지배구조 개편 (가치 재평가) | 0 ~ +4 | 분할·지분매각 등 가치 언락 임박 +2~+4 / 해당없음 0 |
| 5 | 신시장 CAGR (TAM) | 0 ~ +6 | 시장 CAGR 기준: 12%+ 6 / 8~12% 4 / 4~8% 2 / 그 외 0 |

**예시 (KLAC = 18)**: ①10(검사·계측 1위) ②4 ③0(Onto·Nova·Camtek) ④0 ⑤4(PC장비 CAGR 8%)
**예시 (AMAT = 17)**: ①10(증착·식각·CMP 1위) ②4 ③−1(Lam·TEL·ASMI 등 강경쟁) ④0 ⑤4

## 5. 총점 해석 가이드 (코어 /75)

| 총점 | 해석 (질적) |
|---|---|
| 50~75 | 성장·지위가 모두 강함. 단 밸류/시계추 점검 필수 |
| 30~50 | 한쪽(C 또는 A) 강세. 성장 쏠림 여부 확인 |
| 15~30 | 성숙·둔화 또는 사이클 저점. 턴어라운드/저평가 여부로 별도 판단 |
| <15 | 성장 모멘텀 약함. 가치·자산주 관점이면 별도 프레임 |

> ※ 점수만으로 매수/매도 금지. 반드시 ④밸류에이션 ⑤시계추 ⑥VCP 진입과 결합.

---

## 6. (선택) S·L·I·M 정성 확장 모듈

체슬리 코어는 C·A·N만 정량화한다. 필요 시 아래를 **정성 등급(강/중/약)**으로 덧붙인다.

- **S (수급)**: 유통주식·거래량, 기관·외인 순매수, 공급 타이트 여부
- **L (주도주)**: 세부 카테고리 1위 여부 (예: 어닐링=HPSP, 소켓=리노, 검사계측=KLA)
- **I (기관)**: 기관·외국인 보유·순매수 추세
- **M (시장)**: 반도체 업황·지수 추세 (시계추 위치와 연동)

## 7. 동반 산출물 — 종목 퀄리티 카드 (체슬리 양식)

CANSLIM 점수와 함께 1장짜리 카드를 만든다.

```
[로고/종목명/티커]  — 한 줄 정의
┌ 좌측 지표 ───────────────┐  ┌ 매출 구성(최근 분기/연도) ┐
│ 글로벌 점유율 / 순위        │  │ 사업부별 비중             │
│ Gross Margin %             │  └──────────────────────────┘
│ Operating Margin %         │  ┌ 주요 고객사 ─────────────┐
│ 주주환원(배당·자사주)       │  │ TSMC·삼성·SK·Micron 등    │
└────────────────────────────┘  └──────────────────────────┘
어떤 회사인가? (체크리스트 4~5개)
핵심 포트폴리오 (제품/공정)
CANSLIM 총점 [XX.X]  (C x.x · A x.x · N xx.x)
투자 포인트 (1문장)  +  SWOT (강/약/기회/위협)
```

---

## 8. 입력 데이터 체크리스트 (채점 전 확보)

- [ ] 최근 분기 + 전년 동기 영업이익 (C용)
- [ ] 최근 3개 회계연도 영업이익 (A용)
- [ ] 시장점유율·순위, GM%·OPM%
- [ ] 경쟁사 리스트, TAM/시장 CAGR (N용)
- [ ] 지배구조 이벤트 유무 (N④용)
- [ ] 현재가·52주·PER/PBR 밴드 (밸류 결합용)
- [ ] 출처/기준일 명기 (인용 vs 추정 vs 확인필요 구분)

---

## 9. 표준 면책

CANSLIM 점수는 종목 비교용 분석 도구이며 투자 권유가 아니다. 모든 입력 수치는 공시·1차 자료로 재확인하고, 점수는 밸류에이션·시계추·진입 규율과 결합해서만 사용한다. 비중·시점은 본인 판단 및 필요 시 전문가 상담을 거친다.
