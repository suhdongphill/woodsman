## 2. 검증에서 **기각**된 것 (고치지 않음)

- `/admin/feeds` 목업·죽은 버튼 6개 → *"미구현 단계이고 저장이 성공한 것처럼 보이는 조용한 실패가 없다"*
  → 다만 **미구현 표시가 없다**는 지적은 남아 화면을 정직한 형태로 다시 만들었다.
- `/admin` AI 토큰 카드 목업 → *"헤더에 목업이라 밝혀 둠"*
  → 그러나 화면 에이전트가 **`/admin/ai`는 "0/7 연결"인데 대시보드는 "연결됨 206K"** 라는 모순을 따로 잡아
  결국 실집계로 바꿨다. **한 사실이 두 화면에서 다르면 어느 쪽도 못 믿는다.**
- `sitemap`의 목업 종목 URL 8건 → C(종목 실데이터)에서 함께 해소된다.

> 검증 단계가 실제로 값을 했다. "한 종목에 두 가격" 같은 **과장된 근거를 깎아 내고**,
> 심각도를 높음→중간으로 되돌렸다. 반대로 화면 에이전트가 코드 에이전트의 기각을 뒤집기도 했다.

## 3. 검증 없이 바로 고친 것 (근거가 코드에 그대로 있음)

- ⚠ **`registerAction`이 `signupEnabled`를 확인하지 않음** — 화면만 막고 서버는 안 막던 곳.
  가입이 닫힌 상태에서 계정이 생기면 `/privacy`의 "회원정보를 수집하지 않는다"가 즉시 거짓이 된다.
- ⚠ **주택착공 "1천호"** — FRED `HOUST`는 이미 천호 단위(1427)인데 `levelK`가 또 나눴다. `JTSJOL`도 동일.
  `ICSA`(199000, 실제 건수)만 `levelK`가 맞다. → `macro.test.ts`가 이 짝을 고정한다.
- `/disclaimer` 3항이 "실제로 운용하는 계좌"인데 화면은 "모의 투자" → 설정에서 읽어 문장을 맞춤.
- `/privacy` 시행일(08-02)이 본문 개정(08-06)보다 뒤처짐 → 갱신 + 개정 이력 한 줄.
