## 3. ⚠ 아직 안 닫힌 것

### 3-1. 집계 비콘 볼륨 상한 (A3의 남은 절반)

속도 제한은 **반만 동작한다**(2026-08-15 실측: 순차 100건 중 32건 차단, **병렬 120건 중 0건**).
남용은 정확히 병렬로 온다.

- 후속안은 **Cloudflare WAF Rate Limiting 규칙**(무료 등급 1개). 워커 안에서 세는 방식은
  동시 폭주를 구조적으로 놓치므로 **엣지에서** 걸어야 한다.
- ⚠ **급하지 않다.** 남은 것은 실재 화면 숫자 부풀리기다. `/admin/analytics`의 초기 숫자를
  그만큼 덜 믿으면 된다.

### 3-2. 8/7 점검의 미검증 19건

보안 헤더 부재 · 로그인 시도 제한 없음 등. **한 번 훑을 시점이 한참 지났다**(`점검해줘`).

### 3-3. 시드 잔여 점검을 실제로 눈으로 본 적이 없다

`lib/seed-residue`는 테스트 17개로 지켜지고 배포도 됐지만, **경고 카드가 실제로 뜬 화면을
본 적이 없다**(다 지운 뒤에 배포해서 지금은 아무것도 안 뜬다 — 그게 정상 동작이다).
⚠ 다음에 `npm run d1:seed`를 로컬에서 돌릴 일이 있으면 그때 `/admin/diagnostics`를 열어 본다.
