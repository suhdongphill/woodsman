## 4. 오늘 만든 것 중 안 끝난 꼬리

### 4-1. E(시세)의 남은 것

- **C7 자동 갱신** — Cloudflare Cron Trigger 하루 1회(장 마감 후). 지금은 버튼을 눌러야 받는다.
  ⚠ 실패 시 `console.error`를 남기고 **직전 값을 유지**한다(조용한 실패 금지).
- 시가총액은 여전히 **미조회 + 조회처**다. 발행주식수 소스를 정해야 채운다.

### 4-2. ⚠ 아직 안 정한 판단 — 분류 이름을 얼릴 것인가

보고서 스냅숏은 분류 **키만** 얼린다. 관리자가 "성장"을 "공격"으로 바꾸면
**이미 발행된 보고서가 옛 이름을 보여줘야 하는지 새 이름을 보여줘야 하는지**를
먼저 정해야 이름까지 얼릴 수 있다. 지금은 기본 셋이면 고정 문안, 커스텀이면 키를 그대로 쓴다.

### 4-3. 종목 조회의 한계

- 이름·시장·통화·현재가만 채운다. **CANSLIM·편입 논리는 여전히 사람이 쓴다**(그게 맞다).
- 국내는 Yahoo 경유라 **지연·결측**이 있다(화면이 그렇게 말한다). KRX/네이버 어댑터는 아직 없다.
- ⚠ **"조회 없이 직접 입력" 통로를 남겼다.** Yahoo가 죽었을 때를 위한 것이다.

## ⚠ 매번 지킬 것

- `npm run dev`를 **끄고** `npm run check` — 켠 채로 빌드하면 `.next`가 깨져 화면 전체가 500이 된다
- 화면을 바꿨으면 **실제로 띄워서 본다.** ⚠ 이번 세션이 이걸 세 번 어겼다
- **모듈로 쪼갠다.** 판단은 `lib/*`(순수 함수 + 테스트), 질의는 `*-repo`, 액션은 `*-actions`, 화면은 `ui/*`.
  ⚠ 사용자가 화면을 하나씩 테스트하며 오류를 전달한다 — **고칠 자리가 한 곳이어야** 한다
- **빈 칸을 0으로 만들지 않는다.** `Number("")`는 0이다. "안 적었다"와 "0으로 정했다"는 다른 뜻이다
- **운영 데이터를 두드리는 실측은 먼저 묻는다**(이번에 실패 로그인 12회를 사전 합의 없이 보냈다)
- `web/CHANGELOG.md`에 **"왜"** 를 남긴다
- 배포 후 **운영본을 검증한다.** 로컬 통과가 배포 성공이 아니다
- 지시가 `docs/운영지침.md`와 어긋나면 **먼저 말하고**, 진행 여부는 사람이 정한다
