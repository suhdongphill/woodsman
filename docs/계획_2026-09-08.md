## 4. ⚠ 오늘 배운 것 — 규칙으로 남길 것

| 규칙 | 어디서 나왔나 |
|---|---|
| ⚠ **줄이기 전에 잰다** | `rates.json` 977KB가 gzip 뒤 **198KB**였다. 결정은 남았지만 **이유가 바뀌었다** |
| ⚠ **인용은 원문과 대조한다** | 검색은 SEP 장기 중앙값을 3.0이라 했고 **연준 원문은 3.1**이었다 |
| ⚠ **엉뚱한 곳을 가리키는 실패** | 「응답에 텍스트 블록이 없습니다」는 모델이 침묵한 게 아니라 **상한**이었다. 어제 적은 규칙이 **적은 날 다시 걸렸다** |
| ⚠ **초록인데 지키는 게 없는 테스트** | 테스트가 `rates.db`를, CLI가 `pms.db`를 보고 있었다. 하루 종일 **이틀 전 DB를 검사하며 초록**이었다 |
| ⚠ **행 수는 포함의 증거가 아니다** | 지우기 전 대조에서 **스냅숏 28건이 구 DB에만** 있었다. 옮기고 나서 지웠다 |
| ⚠ **그럴듯한 값이 가장 위험하다** | Yahoo `^MOVE`는 MOVE가 아닌데 값(73.10)이 **실제 MOVE 범위와 겹친다** |
| ⚠ **없는 줄 알았는데 다른 곳에 있었다** | 요청한 15개 중 **13개가 이미 수집 중**이었고, SOX도 `/macro/semi`에 1997년부터 있었다 |
