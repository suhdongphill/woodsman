# 막힌 지표 — 어디까지가 진짜 막힌 것인가

## 0. 판단의 사다리 — 위에서부터 시도한다

| 단계 | 무엇 | 왜 이 순서인가 |
|---|---|---|
| ① **공개 API** | FRED·ECOS·Yahoo처럼 키 없이 또는 무료 키로 | 사람 손이 안 들어간다. **유일하게 안 썩는 경로** |
| ② **포털 키 발급** | 가입하면 무료/유료 키를 주는 곳 | 한 번 등록하면 ①과 같아진다 |
| ③ **AI 전사** | 출처는 사람이 주고, 본문은 서버가 받고, 모델은 **옮겨 적기만** | 공개 페이지는 있는데 API가 없을 때 |
| ④ **수기 입력** | 사람이 직접 | ⚠ **여기 오면 대개 안 들어간다** — 2026-09-05에 수기 일곱 개에 값이 **한 점도** 없었다 |
| ⑤ **안 넣는다** | 못 받는다고 적어 둔다 | 「아직 안 붙였다」와 「받을 길이 없다」는 다른 말이다 |

⚠ **③은 값을 지어내는 것이 아니다.** 모델은 사람이 준 URL의 본문에서 숫자를 **옮겨 적기만**
하고, 인용문을 원문과 글자 그대로 대조해 없으면 버린다(개발요구서 v2). 그래도 지표값은
캘린더 날짜보다 위험하므로 **저장은 사람이 누른다.**

## 1. MOVE 지수 (국채 변동성) — ⚠ **함정을 하나 찾았다**

### ⚠ Yahoo `^MOVE`는 MOVE 지수가 아니다

| 확인한 것 | 결과 |
|---|---|
| `^MOVE` 조회 | HTTP 200 · 값 **73.10** |
| 그 심볼의 정체 | **Northern Trust iBoxx 5-Year Target Duration TIPS Index** (NYSE) |
| ICE BofA MOVE인가 | **아니다** |

**이것이 위험한 이유** — 실제 MOVE 지수도 보통 70~120 사이에서 논다. 그래서 73.10은
**그럴듯해 보인다.** 확인 없이 넣었으면 화면이 조용히 틀린 숫자를 신뢰의 얼굴로 내보였을 것이다.
「단위 하나가 800배 틀릴 뻔했다」(2026-08-11)와 같은 종류인데, 이번 것은 **자릿수마저 맞아서
더 나쁘다.**

### 경로 판정

| 단계 | 가능한가 | 근거 |
|---|---|---|
| ① 공개 API | ❌ | FRED 검색 결과 없음. ICE BofA는 **라이선스 배포**다 |
| ② 포털 키 | ❌ | ICE는 개인 무료 키를 발급하지 않는다 |
| ③ AI 전사 | △ | YCharts 등 2차 페이지가 값을 싣지만 **2차 출처**다 |
| ④ 수기 | △ | 주 1회면 충분하나 ⚠ 안 들어갈 확률이 높다 |
| ⑤ 안 넣는다 | ⭐ | **지금 권고** |

### ⭐ 권고 — 대리 지표를 **다른 이름으로** 쓴다

MOVE를 흉내 내지 않고, **자유롭게 받을 수 있는 국채 변동성 대용**을 그 이름 그대로 쓴다.

- `VIXCLS`(주식 변동성)는 이미 받을 수 있다 — 다만 **채권 변동성이 아니다.**
- 국채 선물(`ZN=F`)의 **실현 변동성**은 우리가 직접 계산할 수 있다(Yahoo에서 받아진다).
  ⚠ 이건 MOVE(내재 변동성)와 **다른 것**이다. 이름을 「국채 실현변동성(20일)」로 적고
  MOVE라고 부르지 않는다.

⚠ **판별 조건을 쓴 글은 고쳐야 한다.** 「MOVE가 상위권으로 복귀하면」은 우리 화면으로
확인할 수 없다. 대용을 쓰기로 하면 **판별 조건의 문장 자체를 그 대용으로 다시 쓴다** —
확인할 수 없는 조건을 남겨 두면 약속이 공허해진다.

## 2. 시장 내재 정책금리 확률 (CME 페드워치) — ⭐ **직접 계산할 수 있다**

### CME는 막혀 있다

| 시도 | 결과 |
|---|---|
| `cmegroup.com/services/fed-watch-tool` | **403** |
| `cmegroup.com/CmeWS/...` (내부 API) | **403** |

봇 차단이고, 뚫는 것은 이용약관 문제이기도 하다. **스크래핑은 권하지 않는다.**

### ⭐ 그런데 원재료가 열려 있다

| 확인한 것 | 결과 |
|---|---|
| Yahoo `ZQ=F` (30일 연방기금 선물) | **HTTP 200 · 96.215** |

연방기금 선물은 **100 − 가격 = 해당 월의 평균 실효금리 기대치**로 읽는다.
96.215 → **3.785%**. 지금 실효금리(3.63%)보다 **0.155%p 높다** — 시장이 인상 쪽에
무게를 두고 있다는 뜻이고, 이것이 요청서가 말한 「사람들이 거는 것」이다.

**확률로 바꾸는 방법**은 공개돼 있다(페드워치가 쓰는 것과 같은 논리):
회의가 월 중간에 있으면 그 달의 평균은 「회의 전 금리 × 회의 전 일수 + 회의 후 금리 × 남은 일수」이므로,
그 식을 뒤집으면 회의 후 금리의 기대값이 나오고, 인상폭(0.25%p)으로 나누면 확률이 된다.

| 단계 | 가능한가 |
|---|---|
| ① 공개 API | ⭐ **가능** — Yahoo `ZQ=F` + 회의 일정(우리가 이미 캘린더에 갖고 있다) |
| ② 포털 키 | 불필요 |

### ⚠ 다만 이름을 정확히 붙인다

이렇게 만든 값은 **「CME 페드워치 확률」이 아니다.** 「선물 내재 확률(우리 계산)」이다.
페드워치와 소수점이 다를 수 있고, 그 차이를 우리가 설명할 수 없다.
⚠ **화면에 계산식과 입력(선물 가격·회의일)을 함께 남긴다** — 되짚을 수 없는 확률은
신뢰가 아니라 장식이다.

**난도**: 중간. 회의일 경계 처리가 전부다. 테일러 준칙 확률 옆에 놓으면 요청서 §4의
「모형이 처방하는 것 vs 사람들이 거는 것」이 그대로 완성된다.

## 3. 비트코인 현물 ETF 순유입 — ⚠ **지표가 아니라 결정이 먼저다**

| 단계 | 가능한가 | 근거 |
|---|---|---|
| BTC 가격 | ⭐ 가능 | Yahoo `BTC-USD` **200 · 79,021.85** — 기존 파이프라인 그대로 |
| ETF 순유입 (공식 API) | ❌ | 없음 |
| Farside 공개 표 | △ | `farside.co.uk` **200** — HTML 표. ③ AI 전사 대상은 된다 |
| SoSoValue | △ | 같은 성격의 2차 집계처 |

⚠ **먼저 결정할 것이 있다.** 이건 지표 하나가 아니라 **자산군을 새로 여는 일**이다.
사이트는 지금 거시·주식이고, 크립토를 들이면 화면 구성·묶음·글의 범위가 함께 움직인다.
**지표 추가가 아니라 방향 결정으로 다루기를 권한다.**

⚠ 그리고 Farside는 **2차 집계처**다. 원 출처는 각 발행사 공시이고, 집계처마다 숫자가
조금씩 다르다. 쓰기로 한다면 **「Farside 집계 기준」이라고 화면에 적는다.**

## 4. ISM 제조업·서비스업 PMI — ❌ **돈으로만 열린다**

2026-09-05에 이미 무료 경로를 다 두드렸고(DBnomics 미러는 값이 깨져 있었고 FRED 계열은
라이선스로 내려갔다), 오늘 다시 확인해도 같다.

| 단계 | 판정 |
|---|---|
| ① 공개 API | ❌ |
| ② 포털 키 | ⚠ **유료만** — ISM은 구독 상품으로 판다. 개인 무료 키가 없다 |
| ③ AI 전사 | △ 보도자료 요약은 공개되지만 ⚠ **침체 판정에 그대로 들어가는 값**이다 |
| ⑤ 대체 | ⭐ **권고** |

### ⭐ 권고 — 대체 지표를 쓰되 **ISM이라고 부르지 않는다**

무료로 살아 있는 것을 오늘 다시 확인했다.

| 계열 | 무엇 | 최신 |
|---|---|---|
| `CFNAI` | 시카고 연준 전미활동지수 | 2026-07 |
| `GACDISA066MSFRBNY` | 엠파이어스테이트 제조업 | 2026-08 |

⚠ 둘 다 **ISM이 아니다.** 판정 규칙(`ism_mfg` 50 기준선)을 그대로 옮겨 쓰면 안 되고,
기준선을 다시 정해야 한다 — **지표를 바꾸는 것은 사람이 정할 일**이다.

## 5. 컨퍼런스보드 소비자신뢰지수(CCI) — ⭐ **무료 사촌이 있다**

| 단계 | 판정 |
|---|---|
| ① 공개 API | ❌ 컨퍼런스보드는 유료 |
| ⑤ 대체 | ⭐ `UMCSENT` **미시간대 소비자심리지수 · 최신 2026-07** — FRED에서 무료로 받아진다 |

⚠ **CCI와 미시간은 다른 조사다.** 표본·질문·기준연도가 다르고, 둘은 자주 **반대로** 움직인다
(미시간은 물가에, CCI는 노동시장에 더 민감하다). 그래서 **이름을 바꿔 넣고, 갈릴 때는
갈린다고 적는 편이** 하나로 뭉개는 것보다 정직하다.

## 6. NAHB 주택시장지수 — △ **AI 전사가 맞는 자리**

| 단계 | 판정 |
|---|---|
| ① 공개 API | ❌ FRED에 계열 없음(`NAHBHMI` 없음) |
| ② 포털 키 | ❌ |
| ③ **AI 전사** | ⭐ **권고** — NAHB 공개 페이지 **HTTP 200**, 월 1회 갱신 |

월 1회이고, 출처가 **원 발표 기관 자신**이라 2차 집계처 문제가 없다. 2026-09-05에 만든
「출처는 사람이 · 본문은 서버가 · 인용은 기계가 대조」 경로에 정확히 맞는 모양이다.

## 8. 요약 — 무엇부터 할 것인가

| 지표 | 판정 | 다음 행동 | 난도 |
|---|---|---|---|
| **시장 내재 확률** | ⭐ 공개 원재료로 **직접 계산** | `ZQ=F` + 회의일로 산출, 「우리 계산」이라 명시 | 중간 |
| **NAHB** | ⭐ AI 전사 | 기존 전사 경로에 출처 등록 | 낮음 |
| **CCI** | ⭐ 대체(`UMCSENT`) | 이름을 바꿔 넣고 CCI와 다름을 적는다 | 낮음 |
| **BTC 가격** | ⭐ 가능 | ⚠ 자산군 결정이 먼저 | 낮음 |
| **ISM** | ❌ 유료 | 대체(`CFNAI`·엠파이어) 채택은 **사람 결정** | 중간 |
| **MOVE** | ❌ 라이선스 | ⚠ `^MOVE`를 쓰지 않는다. 대용은 다른 이름으로 | 중간 |
| **BTC ETF 순유입** | △ 2차 집계처 | 자산군 결정 뒤에 | 중간 |

⚠ **포털 키를 새로 발급받아 풀리는 것은 하나도 없다.** 막힌 것들은 키의 문제가 아니라
**라이선스**의 문제다(ISM·컨퍼런스보드·ICE). 반대로, **키 없이 이미 열려 있는데 우리가
안 쓰고 있던 것**이 둘 있었다 — `ZQ=F`와 `UMCSENT`.

⚠ **AI로 풀리는 것은 NAHB 하나다.** 나머지에 AI를 쓰면 그건 전사가 아니라 **추정**이고,
지표값 추정은 이 저장소가 하지 않기로 한 일이다.
