# CANSLIM 스코링 정책 v1 (개선판)

> WoodsMan 프레임워크용 CANSLIM 정량 채점 규칙. 현재 카드(WDC 예시)에서 발견된
> 4대 결함(A 점수 모순, 스케일 붕괴, 배점 불균형, 해자 채점 역전)을 바로잡는다.
> 윌리엄 오닐의 원 기준을 백본으로 하되, 사이클 종목(HDD·반도체)에 강건하도록 보완.

---

## 0. 설계 원칙
1. **단일 스케일**: 7글자 모두 **0~10점**으로 통일. (현재 카드의 25/25/75 혼용 폐기)
2. **변별력**: 임계값만 넘으면 만점이 아니라, 구간별 등급으로 차등.
3. **사이클 강건성**: 음수·저점 기준연도에서 CAGR·YoY%가 깨지는 문제를 명시적으로 처리.
4. **철학 정합**: 과점·해자·고영업이익률을 *플러스*로 채점(투자철학과 일치).
5. **데이터 정직성**: 데이터 없는 항목은 추정하지 말고 `N/A`로 둔다.

---

## 1. 종합 점수 체계

### 1.1 항목 가중치 (합계 100)
| 항목 | 의미 | 가중치 |
|---|---|---|
| C | Current 분기 실적 | 15 |
| A | Annual 연간 실적 | 15 |
| N | New (제품·경영·시장·신고가) | 15 |
| S | Supply & Demand 수급 | 15 |
| L | Leader 상대강도 | 15 |
| I | Institutional 기관 | 10 |
| M | Market 시장방향 | 15 |
| **합계** | | **100** |

> N을 75 → 15로 정상화. I는 리테일이 데이터 확보가 어려워 10으로 소폭 하향.

### 1.2 종합 산출
- 각 항목 **0~10점** 채점 → `종합(100점) = Σ(항목점수 × 가중치/10)`
- 앱 레이더(0~10)와 호환을 위해 **composite10 = 종합/10** 도 병기.

### 1.3 등급 밴드 (기존 8.0/6.5 기준 계승)
| composite10 | 등급 | 액션 |
|---|---|---|
| ≥ 8.0 | 우수 | 비중확대 후보 |
| 6.5 ~ 7.9 | 보통 | 유지·관찰 |
| < 6.5 | 저조 | 축소·제외 |

> **M(시장)은 게이트**: M ≤ 3이면(조정장) composite와 무관하게 신규 매수 보류 권고.

## 2. 항목별 채점 규칙 (0~10)

### C — Current (최근 분기 영업이익/EPS 증가율)
오닐 기준: 최근 분기 EPS YoY **≥25%**, 가속 + 매출 동반.

**기본 매핑 (YoY 증가율 → 점수)**
| YoY | 점수 |
|---|---|
| ≥100% | 10 |
| 50~100% | 8~9 |
| 25~50% | 6~7 |
| 10~25% | 4~5 |
| 0~10% | 2~3 |
| 음수 | 0~1 |

**보정**
- `+1` 가속(이번 분기 증가율 > 직전 분기 증가율), 단 상한 10.
- `−2` 품질 미흡(매출은 정체인데 이익만 급증 = 일회성·원가절감 의심).
- **사이클 보정**: 전년 동기 기준이 음수/저점이면 YoY%는 허수 → 대신
  ① 직전 고점 대비 회복률, 또는 ② QoQ 순차 성장으로 평가하고 **자동 만점 금지**(상한 8).

### A — Annual (연간 영업이익 성장)
오닐 기준: 연간 EPS **≥25%**, **3년 연속** 성장, ROE ≥17%.

**기본**: 3년 EPS CAGR로 매핑(C와 동일 구간표).

**⚠ 사이클 예외 (필수)**: **기준연도(시작연도) 영업이익 ≤ 0이면 CAGR 사용 금지.**
→ 다음 trajectory 루브릭으로 대체 채점:
| 조건 | 가점 |
|---|---|
| 적자 → 흑자 전환 달성 | +3 |
| 3년 연속 이익 개선(우상향) | +3 |
| 전년 대비 +100%↑ 또는 전고점 회복 | +2 |
| 차년도 가이던스/컨센서스 추가 성장 | +2 |
(합산 후 0~10 클립. 단 *회복 사이클*임을 메모하고 상한 9 — 안정적 복리성장과 구분)

### N — New (제품·경영·시장·신고가) + 구조 해자
| 하위 항목 | 만점 | 채점 기준 |
|---|---|---|
| 신제품/신기술 사이클 | 2.5 | 차세대 제품·수요 사이클 진입 |
| 신경영/구조개편 | 2.5 | 분사·턴어라운드·경영진 교체 등 변곡 |
| 신시장/TAM 확장 | 2.5 | 신규 수요처 CAGR(예: AI 니어라인) |
| 신고가/베이스 돌파 | 2.5 | 52주 신고가 근접·정상 베이스 돌파 |
합계 0~10. **해자 보정**: 합리적 과점(소수 경쟁자) = `+1`(상한 10). 경쟁 격화·진입장벽 붕괴 = `−2`.
> 기존 '경쟁기업 수 → 0점' 오류 교정: **과점은 감점이 아니라 가점.**

### S — Supply & Demand (수급)
- 상승일 거래량 급증(평균 대비 +40~50%↑), 축적(accumulation) 우위: 고점.
- 자사주 매입·유통주식 감소: 가점. 대량 신주발행·오버행: 감점.
- 유통주식 적을수록(중소형) 탄력 가점.

### L — Leader or Laggard (상대강도)
- RS Rating **≥80** 핵심. 80~89 → 7~8, 90↑ → 9~10, 70~79 → 5~6, <70 → ≤4.
- 업종 1~3등 + 50/200일선 위 가점. 업종 후발·이평선 하회 감점.

### I — Institutional Sponsorship (기관)
- 기관 보유 기관 수·순매수 증가 추세: 가점. 우량 펀드 신규 편입 가점.
- 과보유(over-owned)·기관 이탈: 감점.

### M — Market Direction (시장)
- Confirmed Uptrend(팔로스루 성립) → 8~10. 분산일(distribution) 누적·조정장 → ≤4.
- 지수 50/200일선 관계로 판정. **개별주는 시장에 종속**(오닐: 4종목 중 3종목).

## 3. WDC 재채점 예시 (개선 정책 적용)

> 같은 데이터로 채점 방식만 바꿨을 때의 변화. **방법론 시연이며 투자 권유 아님.**

| 항목 | 기존 카드 | 개선판 | 근거 |
|---|---|---|---|
| C | 25/25 (=10/10) | **9/10** | YoY +116%(>100%) → 9~10, 매출 동반·가속 확인 시 10 |
| A | 10/25 (=4/10) | **7~8/10** | FY23 적자라 CAGR 무효 → trajectory 루브릭(적자→흑자, 3년 개선, FY26F 대폭 성장). 단 사이클 회복이라 상한 9 |
| N | 23/75 (=3.1/10) | **8/10** | Sandisk 분사(신경영) + AI 니어라인(신시장) + HDD 3사 과점(해자 +1). 기존의 '경쟁=0' 오류 교정 |
| S | — | N/A | 거래량·수급 데이터 필요 |
| L | — | N/A | RS Rating 필요 |
| I | — | N/A | 기관 수급 데이터 필요 |
| M | — | N/A | 지수 추세 판정 필요 |

**핵심 변화**: A는 깨진 CAGR을 trajectory로 대체해 과소평가 해소, N은 해자 채점 역전을 바로잡아 3.1 → 8로 정상화. C는 스케일을 변별 가능한 구간제로 전환.
S·L·I·M은 **데이터 없이 점수를 만들지 않음**(정직성 원칙).

## 4. 구현 메모 (앱 연동)
- 백엔드 `canslim_score(ticker, financials, market)` → 항목별 dict + composite 반환.
- 음수 기준연도 분기 → `use_trajectory=True` 플래그로 분기 처리(2장 A·C 사이클 보정).
- `scores(json)`에 항목점수 + 근거 1줄 + 데이터출처·기준일 저장(현 `canslim_cache` 스키마 확장).
- 카드 UI: 7축 레이더(0~10) + 종합(100) + 등급 밴드. **N 75점 표기 제거**.
