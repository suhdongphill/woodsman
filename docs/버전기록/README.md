## 판을 올리는 기준

- **포털이 독자에게 무엇인지**가 바뀔 때 큰 판을 올린다. 화면 하나·기능 하나는 판이 아니다.
- 판마다 파일 하나: `vN_<한 줄 이름>.md`. 시작 계기 · 결정 · 무엇을 바꿨나 · **무엇으로 쟀나 · 결과** · 다음 판으로 넘어간 이유.
- ⚠ v1·v2는 **나중에 기록을 보고 정리한 것**이다(2026-11-14). 커밋과 CHANGELOG에 근거가 있는 것만 적었다.
