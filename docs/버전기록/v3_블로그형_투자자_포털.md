## 운영자 결정 (2026-11-14)

1. **1순위(티스토리 유입)는 유지한다.** 포털은 1순위를 해치지 않는 자기 원문으로 가치를 채운다.
2. 홈 순서 「바람 → 오늘의 브리핑 → 조류 → 오늘의 기사」는 **클릭 비교를 본 뒤 진행**한다. 비교 결과: 10/31 홈 정리 전후 14일 중앙값 20.5 → 22.5회/일로, 줄지 않았다.
3. **조류 AI 해설**은 브리핑처럼 초안을 쌓고 **운영자가 승인해야 공개**한다.
4. 판 구분은 v1 · v2 · v3로 한다.
5. 히어로 부제는 푸터 문구로 바꾼다(`/admin` 설정).
