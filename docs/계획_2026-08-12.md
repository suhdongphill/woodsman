## A. 배포와 검증 (30분) — ⚠ 가장 먼저

어제 만든 것 중 **배포돼야 의미가 생기는 것**이 셋이다.

### A1. 배포
```bash
npm run cf:deploy        # 0-1이 안 됐으면 이 경로로 우회
```

### A2. ⚠ 마이그레이션 적용 확인
`20260811132602_page_engagement`(PageEngagement · OutboundSource)가 **운영 D1에 적용돼야** 한다.
0-1이 안 된 상태면 GitHub Actions가 안 돌므로 **수동으로 적용해야 한다**:
```bash
npm run d1:migrate       # wrangler d1 migrations apply woodsman-db --remote
```
⚠ 이걸 빼먹으면 비콘이 계속 500을 내고, 라우트가 200으로 삼켜서 **조용히 아무것도 안 쌓인다.**
배포 직후 서버 로그에서 `[analytics] 체류 기록 실패`가 없는지 본다.

### A3. ⚠ 속도 제한 바인딩이 실제로 붙었는지 확인
`wrangler.jsonc`에 `ratelimits`를 추가했지만 **배포 전까지는 무제한 쓰기 그대로**다.
배포 후 로그에 `[beacon] BEACON_LIMITER 바인딩이 없어...` 경고가 **뜨지 않아야** 정상이다.
뜨면 바인딩이 안 붙은 것이다.

### A4. 운영본 검증 (로컬 통과 ≠ 배포 성공)
- `/macro` — 연준 인상확률 카드가 뜨는가. 기준일이 **가장 오래된 투입 지표** 날짜인가
- `/macro/bubble` — 30개 지표 · 8가지 트리거로 나오는가
- `/admin/analytics` — 열리는가. 조회는 쌓이고 체류 표본은 아직 0이어도 정상
- ⚠ **브라우저 확장이 끊겨 8/6부터 육안 확인을 못 하고 있다.** 확장을 살리거나,
  안 되면 curl로 HTML을 받아 확인한다(어제 그렇게 했다)
