## 3. 오늘 만든 것의 꼬리

### 3-1. ⚠ 익명 댓글은 **글 단위 공유 버킷**이다

IP를 저장하지 않기로 해서, 같은 글에 익명 댓글이 10분에 5건을 넘으면 **다음 사람도 잠시 막힌다.**
지금은 트래픽이 없어 드러나지 않지만 **커뮤니티를 열면 정상 방문자가 막힐 수 있다.**
그때 판단할 것: 익명 작성을 아예 닫을지(`requireLoginToComment`), 버킷을 잘게 나눌지.

### 3-2. ⚠ 전역 AI 상한은 **아직 아무도 안 부른다**

모델을 실제로 호출하는 코드가 없다(라우팅은 관리자 미리보기 전용).
**호출부를 만들 때 `routeCandidates({ global })`을 넘기지 않으면 §6이 다시 빈다.**
타입 주석에 못 박아 뒀지만, 주석은 사람을 못 막는다 — 호출부가 생기는 날 테스트를 붙인다.

### 3-3. `.next`가 또 깨졌다 (원인 확인됨)

`npm run check`(build) 뒤에 `npm run dev`를 띄웠더니 `page_client-reference-manifest.js`를
못 찾아 **화면 전체가 500**이 됐다. 지금까지 "dev를 켠 채로 빌드하면"이라고 적어 뒀는데
**반대 순서도 똑같이 깨진다.** 처방은 같다 — `rm -rf .next` 후 재기동.

## ⚠ 매번 지킬 것

- `npm run dev`를 **끄고** `npm run check` — 그리고 **build 뒤에 dev를 띄울 때도** `.next`를 지운다(§3-3)
- 화면을 바꿨으면 **실제로 띄워서 본다** — 오늘은 지켰다(브라우저 확장이 안 붙어 curl로 했다)
- **모듈로 쪼갠다.** 판단은 `lib/*`(순수 함수 + 테스트), 질의는 `*-repo`, 액션은 `*-actions`, 화면은 `ui/*`
- **빈 칸을 0으로 만들지 않는다.** `Number("")`는 0이다
- **화면이 하지 않는 일을 한다고 적지 않는다** — 오늘 `/admin/ai`에서 그 문장을 하나 지웠다
- **운영 데이터를 두드리는 실측은 먼저 묻는다**
- `web/CHANGELOG.md`에 **"왜"** 를 남긴다
- 배포 후 **운영본을 검증한다.** 로컬 통과가 배포 성공이 아니다
- 지시가 `docs/운영지침.md`와 어긋나면 **먼저 말하고**, 진행 여부는 사람이 정한다
