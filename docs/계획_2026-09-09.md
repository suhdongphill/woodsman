## 4. ⚠ 오늘 배운 것 — 규칙으로 남겼다

| 규칙 | 어디서 나왔나 |
|---|---|
| ⚠ **「등록됐다」는 이름이 있다는 뜻이지 값이 있다는 뜻이 아니다** | 여섯 자리 중 다섯이 「있다」고 답했는데 값이 비어 있었다 |
| ⚠ **쓰기 명령은 성공을 말로 하게 시킨다** | `secret put`이 조용히 아무것도 안 했다. `secret bulk`는 말을 한다 |
| ⚠ **실패가 가리키는 곳을 그대로 믿지 않는다** | 「한도 문제일 수 있습니다」가 사실은 우리 SQL 문제였다 |
| ⚠ **이름부터 의심하기 전에 이유를 물어볼 자리를 만든다** | NVIDIA 404. 어제도 오늘도 모델 이름부터 갈아 끼우려 했고, 답은 「계정에 없다」였다 |
| ⚠ **버리는 데에도 이유가 있으면 골라 담는다** | 에러 본문을 버린 이유는 타당했지만(되비침), 그 결과 사흘을 헤맸다 |

⚠ 세 사고가 **전부 같은 병**이다 — 실패가 자기 이유를 말하지 않는 것.
개발사에 두 편으로 남겼다(이야기 21편 · 규칙 16개).
