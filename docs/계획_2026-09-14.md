## 1. 이어서 짓던 것 — 둘 다 하기로 했고, 설계는 정해져 있다

⚠ **하나씩 배포한다.** 겹쳐 올리면 효과를 가린다.

### (A) 용어 링크를 본문에서 누르게 — **이쪽을 먼저**

신뢰 체감이 빠르다. `lib/macro/glossary.ts`는 **이미 있다**(용어 9개 · 1차 출처 · 확인일).
지금은 카드 하단에 한 줄로만 붙는다. 누를 수 있게 만드는 일이 남았다.

| 만들 것 | 어떻게 |
|---|---|
| `/macro/glossary` 공개 페이지 | 패턴은 `(public)/macro/compare/page.tsx`를 그대로 따른다 — `PageHeader` · `Card` · `JsonLd` · `metadata.alternates.canonical` |
| 인라인 `<Term>` 컴포넌트 | 점선 밑줄 + `title` 속성 + `/macro/glossary#<슬러그>` 링크. ⚠ **클라이언트 JS 없이** 한다 — 툴팁 하나에 번들을 늘리지 않는다 |
| `lib/sitemap.ts` | `/macro/glossary` 한 줄 추가 (`changeFrequency: "monthly"`) |
| `CapitalEngineCard` | 하단 한 줄짜리 용어 설명을 `<Term>` 링크로 교체 |

⚠ **규칙은 그대로다** — 확인한 링크만, 원 발표 기관을 대고, 우리가 만든 이름은 우리 것이라고
말한다(`own: true`). 새 용어를 넣을 때 **링크를 확인하고 `checked`를 적는다.**
⚠ CBO·CME는 아직 확인이 안 돼 **빠져 있다**(잠재산출·연방기금 선물). 넣고 싶으면 먼저 확인한다.

### (B) 조각 B — 「생산성·공급」 묶음 신설

지금 `prod_yoy`·`ulc_yoy`가 「생산·제조」에 얹혀 있다. 성격이 다르다 — 저쪽은 「경기가 좋은가」이고
이쪽은 **「수요를 죽이지 않고 물가를 잡을 수 있는가」**다.

| 할 일 | 비고 |
|---|---|
| 묶음 `supply` 「생산성·공급」 신설 | `types.ts`의 `MacroGroupKey`에 추가 · `registry.ts`에 한 줄 등록 |
| `prod_yoy` · `ulc_yoy` 옮기기 | ⚠ **`key`는 그대로 둔다.** 바꾸면 시계열이 통째로 끊긴다 |
| `real_comp_yoy` 추가 | `COMPRNFB`(실질 시간당 보수) — 임금이 **실질로** 오르는지 |
| `pot_gdp_yoy` 추가 | `GDPPOT`(잠재산출) — ⚠ **아래 함정을 먼저 처리한다** |
| `ngdp_yoy`는 그대로 | 「생산·제조」에 남긴다. 산출 규모 이야기다 |

#### ⚠ `GDPPOT`에 함정이 있다 — 먼저 막고 붙인다

**2036년까지 값이 있다.** 관측이 아니라 **추계**이기 때문이다. 그대로 넣으면 지금 파이프라인이

## 2. ⭐ 자본 엔진 — 오늘 정해 둔 것 (다시 정하지 말 것)

전체 판정은 `docs/분석_자본엔진_가용성_2026-09-13.md`에 있다. 요점만.

- ⚠ **스택을 늘리지 않는다.** 요구 초안의 FastAPI·Postgres·Redis·Celery는 쓰지 않는다.
  Workers + D1 그대로. **판단이 두 곳에 생기는 것**이 이 저장소가 가장 크게 데인 사고다.
- ⚠ **점수부터 만들지 않는다.** 원자료 → 관계 → 점수 → 종합. 원자료 없는 종합점수는
  **그럴듯한 숫자를 만들어 낸다.**
- ⚠ **설계서에서 MOVE를 빼야 한다.** ICE 라이선스라 못 받고, `^MOVE`는 **다른 상품**이었다.
  대체를 쓰면 **MOVE라고 부르지 않는다.**
- ⚠ **데이터센터 건설비는 FRED에 없다.** `PRMFGCONS`+`TLOFCONS`로 대리하되 **이름을
  데이터센터라 하지 않는다.**
- ⚠ **vendor financing·GPU 담보금융은 공개 API가 없다.** 지금은 안 넣는다. 거기에 AI를 쓰면
  전사가 아니라 **추정**이다.
- ⭐ **미 재무부 Fiscal Data API가 열려 있다**(무료·키 없음). 네 번째 자동 출처다.
  ⚠ 데이터셋마다 **버전이 다르다** — `v2/accounting/od/debt_to_penny` ·
  `v1/accounting/mts/mts_table_1` · `v1/debt/mspd/mspd_table_1`. (조각 C에서 붙인다)
