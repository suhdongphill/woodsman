# GCRM 조류 해설 프롬프트 v2 — 받은 것과 포털에 넣은 것

## 문서의 핵심

- **방향 판정의 3단 폴백**: ① 사실표가 방향을 알려 주면 그것을 따른다 → ② 없으면 내장표를 쓴다 → ③ 둘 다 없으면 방향을 말하지 않는다.
  방향을 틀리면 숫자 대조는 통과하면서 해석만 반대로 나간다. 이 작업에서 가장 잡기 어려운 오류다.
- **브리핑 구성**: [1] 판정 한 문장(점수 없음) · [2] 본문 2문단 · [3] 단서(마지막 1~2문장은 「이 해석이 틀린다면」) ·
  [4] 이렇게 되면 다시 봅니다(조건 → 판단 변화) · [5] 근거 숫자(접어 둠) · 카드 2~3문장.
- **금지**: 사실표 밖 숫자·인과 · 반영률을 분수로 풀기 · 「~점 올랐습니다」로 끝내기 · 「지켜본다」로 끝내기 · 내부 용어 · 권유.
- **서버 권고**: 항목별 방향 값 하나와 메모 다섯 가지.
  - 두 비교 시점의 부호가 다른 항목
  - 반영률이 가장 낮은 항목
  - 같은 방향으로 움직인 쌍
  - 반대 방향으로 움직인 쌍
  - 자료가 모자라 점수를 내지 않은 항목
- **교체 후 2주간 볼 것**: [3] 단서의 마지막 두 문장. 이 문장이 형식적으로 채워지기 시작하면 프롬프트의 다른 부분도 무너지고 있다는 신호다.

## 포털에 넣을 때 다르게 한 것 (instruction-check)

| 문서 | 포털 | 이유 |
|---|---|---|
| 「서버 파이프라인은 손대지 않는다」 | v2 구성을 **JSON 칸**으로 받는다: verdict · paragraphs · caveat · triggers · evidenceFactIds · card | v1 서버 대조가 JSON을 받는다. 산문으로 받으면 모든 초안이 대조에서 떨어진다 |
| 조류 → 「1년 흐름」, 바람 → 「주 단위 흐름」 | **「조류(1~12개월 흐름)」**를 첫 등장에 쓰고 이후 「조류」 | 운영자 결정(2026-11-14). 홈 첫 문장(「바람과 조류를 설명하는 길잡이」)과 말을 맞추고, 실제 기간(1~12개월)과도 맞춘다 |
| 수준 말 내장표(넉넉/빡빡 …) | 사실표에 **홈 칩과 같은 `levelWord`**(평소보다 크게 높다 …)를 넣는다. 문서의 1순위 「사실표에 수준 말이 있으면 그것을 쓴다」로 집힌다 | 홈 칩과 해설이 같은 점수를 다른 말로 부르지 않게 |
| MODE brief / card 중 하나 | 한 번에 **둘 다** 받는다 | 홈 카드(요약)와 펼친 브리핑이 같은 초안에서 나와야 승인이 한 번이다 |
| 근거 숫자 표 | AI는 **사실 ID만** 준다. 값은 화면이 저장된 사실표에서 그린다 | 숫자는 엔진이 쥔다 |
| 방향 내장표 | 사실표에 **`GCRM_PILLARS.polarity`**(우호형/긴장형)를 넣는다 → 1순위로 집힌다 | 내장표와 설정이 다르면 설정이 이긴다. 대조 결과 지금은 둘이 같다(달러 네트워크 「지배력」 이름만 다름) |
| 길이 600~900자 | 대조 관문은 400~1,000자(크게 벗어난 것만 실패) | 조금 넘친 초안까지 버리지 않게. 목표는 프롬프트에 600~900자로 적었다 |

서버 대조에 새로 넣은 것:

- 판정에 숫자가 있으면 실패
- 본문 2문단, 조건 2~3개
- 조건이 「지켜본다」류로 끝나면 실패
- 내부 용어(기둥 · 발행 · 커버리지 · INSUFFICIENT)가 있으면 실패
- 금지 문체(사료된다 · 제반 여건 · 여지가 있다 · 급등 · 폭락 · 심각한 · 느낌표)가 있으면 실패
- 사실표에 없는 분수가 있으면 실패

## v1 초안 한 건이 보여 준 것 (2026-11-14 09:28Z · claude-sonnet-5 · 판정 보류)

숫자 대조는 통과했다. 그러나 v2가 짚은 약점이 그대로 나왔다.

- 내부 용어: 「6개 기둥 점수는 모두 발행됐지만」, 「커버리지 60%」
- 「10점 올랐습니다」로 끝나는 문장
- 다음 확인 조건 세 개가 모두 「다시 본다」로 끝남
- 시장위험·지정학과 위험 전이의 상승이 **자본에 불리한 쪽**이라는 방향 설명이 없음 — 독자는 「올랐다」를 좋은 소식으로 읽을 수 있다
- 「6/6」은 사실표에 있어 통과했다. v2에서는 발행 수 칸 자체를 사실표에서 뺐다(내부 상태)
