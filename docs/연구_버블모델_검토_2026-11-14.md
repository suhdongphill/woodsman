# AI·반도체 버블 모니터 검토

## 결론

점수는 정직하게 계산되고 있다(50.1 「경계」 재계산 일치). 그러나 3분기 실적 시즌(10/28~11/10) 뒤의 버블 쟁점이 거의 반영되지 않았다.
독자에게는 숫자 하나만 보이고 **방향 · 움직인 이유 · 다음 확인 일정**이 없다.

## 현재 상태 (운영 D1 `BubbleReading`·`BubbleTriggerState` · 공개 `/macro/bubble`)

- 공개 50.1/100 「경계」 · 2026-11-07 기준 · 가장 오래된 판정 2025-12-31 · 28/28 채점.
- 레이어 평균: L1 2.0(6개 모두 2점, 천장) · L2 0.7 · L3 0.4 · L4 1.0 · L5 0.7.
- 90일 넘은 판정 5개:
  - 연간 지표(구조적 지연): rpo_concentration · server_useful_life · ipo_first_day(2025-12-31)
  - 갱신 대상이 있는 것: equip_billings_yoy(06-30) · circular_flag(07-26)
- 3분기 실적 뒤에 갱신하지 않은 수동 지표: capex_guidance(09-10) · oracle_credit(08-31) · neocloud_credit(10-22) · dram_contract_outlook(09-30) · tsmc_rev_yoy(09-30) · sox_runup(09-30).
- 하드 트리거 8개: 마지막 갱신 09-13. 설계상 14일 기준을 크게 넘겼다.
- ⚠ sox_runup 값 칸이 「10월 진행 중(10/26) +87.1%」다. 10월 월말 값이 100% 밑이면 이 지표가 2점에서 1점이 되고, 총점은 약 48.0이 된다(검토자 계산). 월말 값은 확인하지 못했다.

## 잘하는 것

- 결측은 분모에서 빼고 커버리지와 가장 오래된 기준일을 함께 표시한다.
- 뜻이 바뀐 지표는 키를 바꿔 옛 판정과 섞이지 않게 한다.
- 「자체 보정」·「꼬리위험」처럼 한계를 표시한다.

## 문제

1. **이력이 없다.** 판정을 덮어쓰기(upsert)로 저장해 방향·기여도·구성 변경일을 낼 수 없다(`features/bubble/repository.ts:48`).
2. **L1이 천장에 붙어 있고, 같은 CAPEX 분자를 4번 센다**(`catalog.ts:24-51`). L1은 더 나빠져도 점수에 반영되지 않는다.
3. **근거가 적혀 있지 않은 것이 있다.** 레이어 가중치(1.5/1.5/1.2/1.0/0.8)와 구간(20/40/60/80)에 근거가 없다. 레이어마다 지표 수가 달라 지표 하나의 영향력이 다르다. 2000년·2021년 백테스트는 저장소에 없다.
4. **9~11월 쟁점의 반영 상태:**
   - IMF GFSR 2026-10(1차 원문 확인)이 순환 금융·레버리지·사모 직접대출을 경고했다. 모델에 사모신용은 없다.
   - 부외 데이터센터 리스·SPV는 모델에 없다(2차 보도로만 확인).
   - 오라클·CoreWeave 3분기, 하이퍼스케일러 CAPEX 가이던스, MSFT RPO는 반영되지 않았다(모두 2차 보도 · 10-Q 대조 전).
   - 개인 신용융자는 모델에 없다(2차 보도).
5. **길 찾기:** 「무엇이 바뀌었나」·「다음 확인 일정」·「국면이 바뀌는 거리」가 화면에 없다.
