# ⚠ 오늘 확인한 것 — 자동 수집은 **한 번도 돈 적이 없다**

9월 1일에 자동 수집을 만들고 「남은 것: 시크릿 · 유료 전환 · 배포」라고 적었는데,
**셋 다 그대로다.** 확인한 사실은 이렇다.

| 무엇 | 확인 방법 | 결과 |
|---|---|---|
| 배포 | `wrangler deployments list` | **마지막 배포 2026-08-31 14:24 UTC** — 자동 수집 코드는 올라간 적이 없다 |
| 시크릿 | `wrangler secret list` | `AUTH_SECRET`·`AUTH_URL`·`SITE_URL` **셋뿐**. `CRON_SECRET` 없음 |
| 요금제 | 오늘 09-05 19:32(KST) 수집 이력 | **성공 50 · 실패 9**, 사유는 전부 `Too many subrequests` = 아직 무료 |
| 수집 이력 | `MacroIngest` 12건 | **전부 `MANUAL`.** `CRON` 행이 하나도 없다 |

⚠ 즉 **오늘 「자료 가져오기」를 누른 것이 9월 1일 이후 첫 수집**이었다.
누르지 않았다면 지표는 나흘 더 낡아 있었을 것이다. 이것이 자동 수집을 만든 이유다.

```bash
# ① 시크릿 (32자 이상)

# ③ 배포 (①②를 끝낸 뒤에)
cd web && npm run deploy

# ④ 확인 — /admin/macro 이력에 「자동」 배지가 뜨고 실패 0건이면 끝났다 (다음날 06:00 KST)
```

⚠ 순서가 중요하다. 유료 전환 전에 배포하면 **매일 같은 9개가 실패한다.**
