index.html 마지막 완성 단계야.
데이터 내보내기/가져오기 기능과 전체 UI를 다듬어줘.

──────────────────────────────────────────
[데이터 관리 기능]
──────────────────────────────────────────
1. JSON 내보내기
   - 우측 상단 메뉴에 "내보내기" 버튼
   - localStorage 전체 포트폴리오 데이터를 JSON 파일로 다운로드
   - 파일명: "stocklens_backup_{YYYYMMDD}.json"
   - 마지막 내보내기 날짜를 localStorage에 기록

2. JSON 가져오기
   - "가져오기" 버튼 → 파일 선택 다이얼로그
   - 파일 유효성 검사 (StockHolding 구조 확인)
   - "기존 데이터에 병합" vs "전체 교체" 선택 모달
   - 성공 시 토스트 알림 표시

3. 백업 알림
   - 마지막 내보내기로부터 30일 경과 시 상단 배너 표시
   - "지금 백업" 버튼으로 즉시 내보내기 실행

──────────────────────────────────────────
[UX 개선 사항]
──────────────────────────────────────────
1. 토스트 알림 시스템
   - 종목 추가/수정/삭제 성공: 초록 토스트
   - API 오류: 빨간 토스트
   - 우측 하단 표시, 3초 후 자동 사라짐

2. 키보드 단축키
   - N: 종목 추가 모달 열기
   - ESC: 모달 닫기
   - ?: 단축키 도움말 표시

3. 빈 상태(Empty State) 개선
   - 포트폴리오가 비어있을 때: 일러스트 + "첫 종목을 추가해보세요" 안내
   - 필터 결과가 없을 때: "검색 결과가 없습니다" 메시지

4. 반응형 레이아웃
   - 1280px 이상: 카드 4열 그리드
   - 768~1280px: 2열 그리드
   - 768px 미만: 1열 리스트

5. 로딩 최적화
   - 앱 초기 로딩 시 현재가 자동 조회 (백그라운드)
   - 각 카드 로딩 상태 스켈레톤 개별 표시
