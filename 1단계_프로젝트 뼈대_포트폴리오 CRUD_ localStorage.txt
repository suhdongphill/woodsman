StockLens라는 개인 주식 포트폴리오 관리 웹앱을 만들어줘.
단일 HTML 파일(index.html)로 만들고, CDN으로 React 18, Tailwind CSS, Chart.js를 로드해.
서버 없이 브라우저에서 바로 열리는 구조야.

──────────────────────────────────────────
[데이터 모델] localStorage key: "stocklens_portfolio"
──────────────────────────────────────────
StockHolding {
  id: string            // crypto.randomUUID()
  ticker: string        // "AAPL" or "005930.KS"
  name: string          // 종목명
  industry: string      // 산업 카테고리
  avgCost: number       // 평균매입단가
  shares: number        // 보유 수량
  currency: "KRW"|"USD"
  weight: "확대"|"유지"|"축소"
  investIdea: string    // 투자 아이디어 메모
  addedAt: string       // ISO string
  updatedAt: string
}

──────────────────────────────────────────
[구현할 기능]
──────────────────────────────────────────
1. 앱 초기화
   - localStorage에서 포트폴리오 데이터 로드
   - 데이터 없으면 빈 배열로 시작

2. 대시보드 (메인 화면)
   - 상단 헤더: 앱 이름 "StockLens" + "종목 추가" 버튼
   - 보유 종목 카드 그리드 (종목명, 티커, 산업, 평균매입단가, 수량, 비중전략 배지 표시)
   - 종목이 없으면 "포트폴리오에 종목을 추가하세요" 빈 상태 화면

3. 종목 추가 모달
   - 입력 필드: 티커(필수), 종목명(필수), 평균매입단가(필수), 수량(필수)
   - 드롭다운: 통화(KRW/USD), 산업 카테고리, 비중전략(확대/유지/축소)
   - 텍스트에어리어: 투자 아이디어
   - 산업 카테고리 옵션: 반도체·IT부품 / 소프트웨어·플랫폼 / 바이오·헬스케어 /
     소비재·유통 / 금융·핀테크 / 에너지·소재 / 산업재·기계 / 통신·미디어 / 기타
   - 저장 시 localStorage 업데이트 후 모달 닫기

4. 종목 수정
   - 각 카드에 "수정" 버튼 → 기존 값이 채워진 수정 모달 열기
   - 저장 시 updatedAt 갱신

5. 종목 삭제
   - 각 카드에 "삭제" 버튼 → "정말 삭제하시겠습니까?" 확인 모달
   - 확인 시 localStorage에서 제거

──────────────────────────────────────────
[UI 디자인 방향]
──────────────────────────────────────────
- 다크 테마 (배경 #0f1117, 카드 #1a1d27)
- 포인트 컬러: 에메랄드 그린 (#10b981)
- 수익 양수: 초록, 음수: 빨강
- 비중 배지: 확대=초록, 유지=노랑, 축소=빨강
- 폰트: Google Fonts에서 "Pretendard" 또는 "Noto Sans KR"
- 카드에 hover 시 미세한 상승 애니메이션
- 모달은 backdrop blur 처리

──────────────────────────────────────────
[기술 제약]
──────────────────────────────────────────
- 외부 API 호출 없음 (이 단계에서는 더미 데이터 사용)
- 현재가 필드는 일단 avgCost로 대체 (다음 단계에서 연동)
- 모든 상태는 React useState로 관리
- 페이지 새로고침 후에도 데이터 유지 확인
